# Basic Programs

This repository contains the simple programming problems and concepts I learn on a daily basis in college.

I push my practice programs here as I learn. The code may be basic or experimental, but it shows my learning journey and can be useful for beginners who are exploring programming.

## Contents

- **CPP/** - C++ practice programs, data structures, algorithms, recursion, sorting, searching, mathematics, and object-oriented programming
- **Computer Network/** - Computer networking practice and notes
- **Shell/** - Shell scripting practice

## Who Is This For?

This repository is mainly for:

- Beginners starting to learn programming
- Students looking for simple practice problems

## Note

These programs are added as part of regular learning and practice. Some solutions may be simple, incomplete, or written in different styles as I continue improving.
